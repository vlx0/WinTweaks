# WinTweaks

Панель скрытых настроек Windows одним окном. Вместо `regedit`, поиска по форумам и правки ключей руками — тумблеры с описаниями.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source · неделя 4 — «Сделай винду своей» · день 25.**

---

## Возможности

- **Проводник:** скрытые файлы, расширения, «Этот компьютер», компактный режим, классическое контекстное меню
- **Панель задач:** секунды в часах, скрытие поиска / виджетов / Copilot, выравнивание влево
- **Внешний вид:** тёмная тема для приложений и системы, прозрачность
- **Приватность:** история буфера, рекламный ID, Bing в поиске
- Состояние читается из реестра при запуске — видно что уже включено
- «Применить» и «Сбросить к дефолту»
- Авторестарт проводника после твиков, которым это нужно

## Установка

git clone https://github.com/vlx0/WinTweaks.git
cd WinTweaks
python -m pip install -r requirements.txt
python run_wintweaks.py

Или `start.bat` — запуск с правами администратора (запросит UAC).

Нужен Windows 10+ / 11 и Python 3.10+.
